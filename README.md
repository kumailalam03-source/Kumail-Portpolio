# Kumail — AI Creator Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript. It can be deployed to Vercel from a GitHub repository without a build step.

## Files
- `index.html` — website and SEO metadata
- `robots.txt` — crawler instructions
- `sitemap.xml` — sitemap for search engines
- `favicon.svg` — browser icon
- `og-image.svg` — social sharing image
- `kumail-alam.jpg` — optimized profile portrait used in the homepage hero

## Deploy to Vercel
1. Upload these files to the root of a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Use the default settings. No framework or build command is required; the site is static HTML.
4. Deploy and open the generated URL.

## Important SEO setup before launch
1. The canonical URL, structured data URL, robots.txt sitemap URL, and sitemap entry are already set to `https://kumail.info/`. Make sure this domain is connected to your Vercel project and that HTTPS works.
2. Confirm the YouTube channel links and change the music channel link if your actual channel URL differs.
3. Add the deployed site in Google Search Console, verify ownership, and submit `/sitemap.xml`.
4. Make the portfolio genuinely useful over time: publish original tutorial pages/articles, link them from the site, and keep project descriptions accurate.
5. Test mobile usability and performance after deployment.

## SEO note
SEO metadata, semantic headings, structured data, crawl files, and responsive design help search engines understand the site, but they cannot guarantee rankings. Search visibility depends on useful original content, competition, links, site quality, and time. Do not add repetitive keywords or claim projects/features that are not real.
